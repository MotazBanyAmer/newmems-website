# NEW MEMS Website

A pixel-perfect, fully responsive clone of the [NEW MEMS](https://newmems-website.replit.app/) website: **AI-integrated MEMS hardware for computing, sensing, and wearable health**, led by Dr. Fadi Alsaleem.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS** (configured with exact light/dark HSL design tokens, Syne display typography, and Inter sans font)
- **Framer Motion** (for smooth scroll animations and entrances)
- **Lucide React** (icons matching the original design)
